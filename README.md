# 秦岭归云

> 中式乡村悬疑题材 · 单视角叙事游戏 · 开发资料库
> 主角：沈怀谷 ｜ 结构：七日七章 ｜ 单轨流程时长：60–90 分钟

《秦岭归云》是一个中式乡村悬疑叙事游戏项目。本仓库收纳从小说改编到可玩原型过程中产生的全部设计与制作资料。

---

```

├── 原型/

│   ├── 秦岭归云_制作路径与技术选型_v0.1.html  技术选型与制作路径
```

## 可玩原型

`原型/index.html` 为零依赖单文件页面，直接用浏览器打开即可运行，无需构建。

## 文档口径说明

各文档之间曾出现过设定冲突，统一以 `秦岭归云_口径冲突补丁_v1.1` 的修订为准。
