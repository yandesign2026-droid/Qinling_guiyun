# 秦岭归云 · 环境音乐与音景

**14 条 · 纯合成 · 无版权风险 · 环境层可无限循环**
生成：`_tool/make_music.py`（合成）+ `_tool/post_music.py`（响度分层与循环）

---

## 唯一的一条音乐规则

邪修摄六魂，**缺第七**。所以全片的音乐只用 **全音阶**。

全音阶（D 起）恰好只有六个音：

```
D  E  F#  G#  A#  C      ← 六个音，第六个之后转回 D 的八度
```

它自己就是一个走不出去的圆——全音阶没有纯五度，没有属主关系，
没有"解决"。任何一个音都可以是起点，也永远到不了终点。

**第七个音在全片从不出现。**

只有在真结局（第六盏灯灭了，E9 触发）才第一次出现一个不属于全音阶的音：

```
F♮  （349.23 Hz）
```

那是全片唯一一个"不属于这个阵"的音。它响起的时候，就是阵破的时候。
`MUS05_终局灯灭` 第 8.6 秒，埙吹这一声，孤零零的，前后都有留白。

> 这条规则不是装饰。玩家不会意识到自己在听全音阶，
> 但他会隐约觉得这段音乐"回不了家"——这正是村子的状态。

## 响度阶梯（相对配音 rms 0.13）

| 层 | rms | 为什么 |
|---|---|---|
| **环境 AMB** | 0.055 | 比台词低 8dB。它永远当背景，**不得盖过任何一句对白** |
| **音乐 MUS** | 0.105 | 与台词相当。但它出场时通常没有对白 |
| **钉音 STG** | peak 0.88 | 要的是冲击，不按响度管 |
| 配音 | 0.130 | 基准 |
| 环境叙事句 | 0.090 | 比角色台词轻 3dB |

第一版环境层做到 0.28，比配音还响——已压到 0.055。

## 环境层 AMB（6 条 · 23 秒 · 无缝循环）

首尾做了 1.6 秒交叉淡化，**可无限循环不掉针**。接缝跳变实测 0.003–0.033（低于可闻阈值 0.05）。

| 文件 | 挂点 | 里面有什么 |
|---|---|---|
| `AMB01_山雾` | D1 入村、室外 | 低频山风 + 湿冷的空气 + 每 3 秒一次很远的闷响 |
| `AMB02_客栈夜` | 归云居内 | 极低 drone + 老木头自己响 + 远处的风 |
| `AMB03_墙内` | 客房夜、墙里 | 36Hz 附近的胸腔压迫 + 闷住的抓挠，全部低通到 900Hz |
| `AMB04_井底` | 井边、墓穴 | 巨大空间 + 水滴 + 深。混响尾长达 0.23 秒 |
| `AMB05_破庙` | 后山破庙 | 穿堂风 + 干燥（高通掉了低频的湿）+ 两声极轻的铃 |
| `AMB06_雾散` | 终局后 | **全片唯一有调性的环境层**——因为阵破了。风几乎停了 |

`AMB06` 是唯一一条能听出音高的环境层。前五条都刻意避免调性。

## 音乐层 MUS（5 条）

| 文件 | 时长 | 挂点 | 设计 |
|---|---|---|---|
| `MUS01_归云主题` | 15s | 开场、过场 | 埙，四个音，**停在第六音上不解决** |
| `MUS02_陈素心` | 22s | 她现身的每一场 | 低弦，三个长音，**每句句尾都往下坠**——和她的声线同一个规则 |
| `MUS03_守墓人` | 24s | 老板娘 | 磬 + 冷 drone。完整、对称、没有情绪。正因为完整才可怕 |
| `MUS04_阵眼` | 30s | D5–D6 破阵 | 六音循环上行三轮，**第七音永远不出现** |
| `MUS05_终局灯灭` | 34s | E9 真结局 | 前 8 秒全音阶下行 → 8.6 秒第一次响 F♮ → 20.5 秒一声磬 → 只剩风 |

`MUS02` 的句尾下坠不是巧合：陈素心的台词原文标注是"句尾往下掉"，
配音用 pitch -24Hz 做，音乐用频率下滑同步做。视觉、听觉、音乐三处说同一件事。

## 挂点速查（场景 → 放什么）

| 场景 | 环境层 | 音乐层 |
|---|---|---|
| D1 村口 / 入村 / 山路 | AMB01 | MUS01 |
| D1–D6 归云居（堂屋、客房） | AMB02 | — |
| D2 西厢房夜（墙里抓挠） | AMB03 | — |
| D3 后山破庙 | AMB05 | MUS03 |
| D4–D6 井边 / 墓穴 | AMB04 | MUS03 / MUS04 |
| D5 拾骨坑 | AMB01 | MUS04 |
| D6 陈素心现身 | — | **MUS02** |
| D7 第七夜 / 破阵 | AMB04 | MUS04 |
| 结局 A（他成了门） | — | STG03 |
| 真结局 E9（第六盏灯灭了） | AMB06 | **MUS05** |

**规则**：同一时刻只跑一层环境 + 最多一层音乐。环境层常驻，音乐层按节点淡入淡出（交叉 2 秒）。

## 技术说明

- 纯 Python stdlib 合成，**无采样、无外部音源、无版权风险**
- 乐器为物理建模近似：埙（正弦+气声+慢起音）、古琴（泛音列+拨弦包络+弯音）、
  磬（不谐和泛音比 2.76 / 5.40 / 8.93）、弦乐（奇次泛音锯齿+颤音）
- 44.1kHz / 16bit / 立体声
- 环境层做了 1.6 秒交叉淡化的无缝循环，可直接 `loop = true` 播放
- 想改任何一个音高，改 `_tool/make_music.py` 顶部的 `WHOLE` 和 `SEVENTH` 即可
